# Application Component

* [Agent Config Generator](/components/agent-config-generator.md) - calypso agent init writes agent-tool deny rules (claude-code, codex, opencode).
* [CLI Component](/components/cli-component.md) - Cobra-based CLI in cmd/calypso with 20+ commands.
* [Keychain Component](/components/keychain-component.md) - internal/keychain — macOS Keychain (security) and Linux libsecret (secret-tool) backends.
* [Operation Broker](/components/operation-broker.md) - Hardened in-process executor and loopback HTTP capability service for Trusted Operations.
* [Platform Sync](/components/platform-sync.md) - calypso sync fly|vercel|k8s pushes an env's real values into a platform secret store.
* [Vault Component](/components/vault-component.md) - internal/vault — encrypted vault, environments, file locking, backups.
