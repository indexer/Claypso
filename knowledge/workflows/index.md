# Workflow

* [Brokered Operation Workflow](/workflows/brokered-operation-workflow.md) - An agent invokes an opaque capability while Calypso alone resolves and uses the bound credential.
* [Pull Workflow](/workflows/pull-workflow.md) - Export vault to .env in one of three modes — real, safe (masked), or wipe (run command then shred).
* [Push Workflow](/workflows/push-workflow.md) - Import an on-disk .env into the vault with a diff summary and confirmation.
